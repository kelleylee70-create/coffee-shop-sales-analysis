# ☕ Coffee Shop Sales Analysis

## Project Overview

This project analyzes coffee shop sales data using SQL to identify sales trends, customer purchasing behavior, product performance, and business opportunities.

The goal is to answer real-world business questions using data and present findings in a clear, professional format.

---

## Objectives

- Analyze sales performance
- Identify top-selling products
- Calculate total revenue
- Discover peak business hours
- Compare product categories
- Provide business recommendations

---

## Tools Used

- SQL
- SQLite
- DB Browser for SQLite
- GitHub
